# autoupdateyml

Tooling for keeping YAML files up to date automatically.

## Status

Scaffolding only. No implementation yet.

## Layout

```
src/                 source code
tests/               tests
.github/workflows/   CI
```

## Getting started

```bash
git clone https://github.com/Argado2248/autoupdateyml.git
cd autoupdateyml
```

Pick a runtime and add the appropriate manifest (`package.json`, `pyproject.toml`, `go.mod`, ...) before writing code.
